# gdgs_scs: a fork of GDGS for space-combat-sim

**The real work is [GDGS by ReconWorldLab](https://github.com/ReconWorldLab/godot-gaussian-splatting), and the credit is theirs. Get the original there.**

This fork exists to customize the renderer for one project, [space-combat-sim](https://github.com/jrssae/space-combat-sim). It is vibe coded, so it isn't intended or optimized for anyone else's use, but everyone is welcome to it if they want.

The addon is renamed `addons/gdgs_scs/`. [PATCHES.md](addons/gdgs_scs/PATCHES.md) lists every change from upstream's v3.3.0 and how to revert it.
